# The Polite Scraper — FlyRank A9

## Target classification

- **Site:** [Books to Scrape](https://books.toscrape.com) — a public sandbox built by Zyte specifically for practicing web scraping.
- **Why this site:** its homepage states it exists to be scraped for practice. No other site is touched by this project.
- **Scope:** the first 3 catalogue pages only (`page-1.html` to `page-3.html`), and the 60 book detail pages linked from them.
- **Data collected:** title, price, availability, star rating, description, and the product URL for each book — all public data already present in the page HTML.
- **robots.txt check:** see below.
- I will not reuse this code on another site without checking its rules and terms first.
